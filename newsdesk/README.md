# News-desk feed

Copied from the local news-desk topic set. The app loads these files over the same origin:

- `sections.json` — 10 sections
- `catalog.json` — per-story section, tags, dek (kept outside episode/2)
- `topics/newsdesk-50.globedesk.json` — all 50 stories as `globedesk.episode/2`
- `episodes/` — shorter story episodes from the same set

Pins and `[UNKNOWN]` marks are left as authored. Refresh by copying the files here again; do not invent topics.
