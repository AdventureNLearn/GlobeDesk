GlobeDesk is a local, free newsdesk and video studio on a talking globe, built by AdventureNLearn.

People create their own stories, drop pins on a free street-level globe, write cards and captions, attach their own video, images and audio (kept in the browser, never uploaded to a server), place that media as cards, popups, screen overlays or geo-anchored panels, mix sound, and export a .globedesk project or a local WebM recording.

No account, no required API key. Code is MIT; AdventureNLearn content is CC BY 4.0. v1.0.1 Official Release: it opens on Frogpost by @AdventureNLearn (48 sample stories, approximate locations, as reported, not verified; removable). An Archive page keeps a card for every show and story ever added.

The base map is a separate core layer. User content never modifies the map style or tiles.
