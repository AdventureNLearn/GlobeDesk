# Template guide pack

This is a blank starting point. Copy the folder, rename it, and set `guidePack` in `js/config.js` to the folder name.

Replace `assets/*.jpg` with your own character stills (idle, talk, success, hint, salute). Add a `assets/vo/` folder of WAV files named like the line ids (`start.wav`, `spin-brief.wav`, …) and list them under `voices` in `manifest.json`.

See [../README.md](../README.md) for the full “make your own guide” notes.
